URUCHOMIENIE (Opcja B – lokalny serwer)
1) Otwórz folder w Eksploratorze.
2) W pasku adresu wpisz: cmd  (Enter)
3) Wpisz:  python --version  (lub: py --version)
4) Uruchom serwer:  python -m http.server 8000   (lub: py -m http.server 8000)
5) Otwórz w przeglądarce: http://localhost:8000
